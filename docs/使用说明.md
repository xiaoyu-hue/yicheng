# 一键成城 · 使用说明

点一下，生成一座只属于这颗种子的古城。这份说明讲清三件事：怎么打开、怎么玩、怎么看懂这张图。

## 一、打开方式

**在线版（推荐）**：打开 [xiaoyu-hue.github.io/yicheng](https://xiaoyu-hue.github.io/yicheng/)，手机、电脑都行，不用安装任何东西。生成全程在你自己的浏览器里完成，不经过服务器，也不收集任何数据。

**双击版**：到仓库的 [Releases](https://github.com/xiaoyu-hue/yicheng/releases) 页下载对应系统的压缩包，解压后双击运行（Windows 是 `yicheng.exe`），浏览器会自动打开游玩页面，不用装任何东西；玩完关掉那个黑色程序窗口即可。

**本地版**：适合会用命令行的朋友，从源码运行（需要 Go 1.22+）：

```bash
git clone https://github.com/xiaoyu-hue/yicheng.git
cd yicheng
go run .   # 然后打开 http://localhost:8080
```

## 二、界面一览

| 控件 | 作用 |
|---|---|
| **换一座城** | 随机抽一颗新种子，立刻生成一座新城 |
| **种子** 输入框 | 显示当前城的种子；也可以自己输入任意整数 |
| **按种子找城** | 按输入框里的种子，精确重现那座城 |
| **规模** 下拉框 | 小城 / 中城 / 大城，切换后当前种子按新规模重新生成 |
| **格局** 下拉框 | 山水 / 棋盘 / 水乡三种格局外加「一郡之地」，切换后当前种子按新格局重新生成（见第四节） |
| **皮肤** 下拉框 | 宣纸 / 春 / 秋 / 冬 / 夜五套配色，只换颜色不换布局（见第四节末） |
| **下载 PNG** | 把当前城导出为 2560×1920 的图片，适合发朋友圈、做壁纸 |
| **下载 SVG** | 把当前城导出为矢量图，放大不糊，适合打印装裱 |
| **下载海报** | 把当前城（或郡）导成竖版分享海报：城名大字＋图＋城谱＋落款印章 |
| **复制城链接** | 把当前这座城的专属链接复制下来，发给朋友点开直达 |

图下方有一行**城谱**：一句档案语＋六项从生成数据里数出来的真数字（单城是坊、市集、城周、屋舍、城门、水道；郡图是城池、辖县、村镇、官道、大河、田野）。像「城周 9.8 里」这样的长度是按图上比例折算的示意值，图个意境。

工具栏右侧还有两个视图按钮：**平面图**就是一直在看的地图；点**立体沙盘**，同一座城会拔地而起成立体模型——坊块按用途定高（衙署最高、园林最矮），衙署、寺庙、学宫带大屋顶，每间屋舍带小屋顶，城墙立成高墙、城门有门楼。操作：按住拖动旋转、滚轮或双指缩放、右键拖动平移；它默认会自己慢慢转，你一动手它就停下。换种子、换格局、换皮肤，沙盘会跟着重建（夜皮肤是夜里的光线）。郡图暂时只能看平面图，沙盘在路上。

图上还有四样固定元素：左上角的**指北针**（标了北向）、图下方的**城名**与「种子」标注、右下角的**落款**（写着这座城是第几号种子、哪种规模）。

## 三、种子玩法

**种子就是一座城的身份证。** 同一颗种子，生成的城永远一模一样——城名、城墙形状、每条街道、每个坊的名字都不会变；换一颗种子，整座城从头再来。

好玩的用法：

- **分享一座城**：点「复制城链接」，把链接发给朋友，对方点开就直达这座城；也可以口头报种子数字（比如微信发一句「去看看 42 号城」），对方在输入框里填上同一个数字，效果一样。
- **纪念日种子**：用生日、纪念日当种子（如 `19900101`），生成一座「那一天的城」，下载下来当礼物或纪念图。
- **盲盒种子**：随手敲几个数字，看看会开出什么样的城。
- **同种子不同规模**：同一颗种子分别用小城 / 中城 / 大城打开，是三座同源的城，布局神似又各不相同，适合凑一套图。

## 四、两种格局

| 格局 | 长什么样 | 气质 |
|---|---|---|
| 山水格局 | 坊界是不规则的多边形，城墙顺着坊界起伏，街道从城门蜿蜒到城心 | 顺势而建的山水小城 |
| 棋盘格局 | 方正城墙、棋盘街坊、十字大道纵横，县衙居北中、东市西市隔街对峙 | 唐长安式的都城秩序 |
| 水乡格局 | 在山水的城身上穿一条运河、再分一条支渠入河，路与水交汇处架桥，临水坊变成水市与码头，河面泊着小船 | 江南水乡的枕河人家 |
| 一郡之地 | 不是一座城，是一郡：郡城居中偏北，辖县环布四方，村镇散落乡间，大河横贯、官道相连 | 一砖一瓦皆由算法排布的「一郡山河」 |

选了「一郡之地」时，规模下拉会变成辖县数：小郡 3 县、中郡 4 县、大郡 5 县。郡图里的每座城都是按各自的种子真生成的完整城池（把种子链接发给朋友，对方点开是同一郡）；城名标在城的上方，村镇名标在村子下方，金色的粗线是官道、细线是乡道，路过河处有桥，角落的「∧」形符号是山峦。

同一颗种子、同一规模，两种格局是两座完全不同的城——等于种子数量翻倍。网址里格局记在 `mode` 参数里，分享链接会把格局一并带上。棋盘格局的坊更多（小城 25 坊 / 中城 36 坊 / 大城 49 坊），坊名库用完一轮后，第二轮的坊改称「里」、第三轮改称「巷」，全城不会重名。

两种格局都有护城河（环城一圈、城门处有桥）和城外景（田垄与村落）。

**顺带说皮肤**：同一座城还能换五套「皮肤」——宣纸（默认）、春、秋、冬、夜。皮肤只换配色，城的布局、名字一概不变，所以一座好城可以出五张不同气质的图：春日嫩绿、秋日金黄、冬日雪素、夜里深蓝配灯火色的字。种子链接会把皮肤一并带上，朋友点开看到的和你完全一样。

## 五、规模怎么选

| 规模 | 大致坊数 | 适合 |
|---|---|---|
| 小城 | 十几坊 | 图面清爽，适合做头像、手机壁纸 |
| 中城 | 二十坊上下 | 细节与清爽兼顾，默认推荐 |
| 大城 | 近三十坊 | 街网最密、最有都城气象，适合打印欣赏 |

## 六、看懂这张图

坊块的颜色就是它的用途：

| 颜色 | 坊的种类 |
|---|---|
| 粉褐 | 县衙（城心，全城的中心） |
| 金黄 | 市集（东市、西市、南市、北市） |
| 浅金 | 寺庙 |
| 青绿（淡） | 学宫 |
| 草绿 | 园林 |
| 米黄（深） | 驿站（东门旁的迎送驿） |
| 米黄 | 民居坊（名字如听雨坊、栖凤坊） |

其它元素：深色粗线是**城墙**，墙上四个缺口是**城门**（东门、南门、西门、北门，图上标了字）；金色线是**大道**（山水格局是四门直达城心，棋盘格局是十字大道）和**环城道**；民居坊和市集里的小三角是**屋顶**；城墙外那圈蓝带是**护城河**，城门正对处有小桥；城南的蓝色曲线是**河流**，古城多傍水而建，这里取「城南有河」的格局；城外浅绿与浅黄的方块是**田垄**，零星的小屋顶是**村落**。水乡格局里再加三样：穿城的**运河**（青蓝色水道）、水道与道路交汇处的**桥**（金色短线），以及运河上的**小船**；临水的青绿色坊是**水市**（水市、河市、桥市、津市），土黄色的是**码头**。

## 七、下载与打印建议

- **发朋友圈 / 做壁纸**：用 PNG，尺寸足够清晰。
- **打印装裱**：用 SVG（矢量图，印多大都不糊）。打印店打开 SVG 文件即可；纸张选 A4 或 A3、偏哑光的纸，宣纸底色的效果最好。
- 文件名会自动带上种子（如 `yicheng-42.png`），日后凭文件名里的种子就能找回这座城。

## 八、常见问题

**第一次打开有点慢？**
建城引擎约 2.8 MB，第一次需要加载，慢网络下等几秒属正常；加载完之后点一次出一座城，很快。浏览器会缓存引擎，之后再打开基本秒开。

**手机上能玩吗？**
能。在线版就是为手机和电脑共同设计的，按钮和输入框都适配了小屏幕。

**下载的图存在哪了？**
存在你浏览器默认的下载文件夹里，文件名是 `yicheng-种子.png` 或 `yicheng-种子.svg`。

**为什么朋友输入同一种子，看到的城和我一样，连名字都一样？**
这正是种子的设计：整座城（包括城名和每个坊名）都由种子算出，不含任何随机或时间因素，所以谁打开都一样。

**能离线用吗？**
在线版第一次打开需要联网加载引擎；本地版（从源码运行）完全离线可用。

**这个程序收费吗？可以商用吗？**
免费。代码以 GPL-3.0 许可证开源：可以商用、可以修改，但再发布时须同样以 GPL-3.0 开源并保留版权声明。文档以 GFDL 1.3 发布。详见仓库的 `LICENSE` 与 `LICENSE-DOCS`。

**生成的城是真实存在的吗？**
不是。城名、坊名、布局全部由算法虚构，与真实地名如有雷同纯属巧合。

## 九、隐私

在线版不设服务器、不收集、不上传任何数据：你输入的种子和生成的图只存在于你自己的浏览器里。本地版同理。
